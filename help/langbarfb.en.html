LangBarFB

A keyboard layout switcher: it shows the current layout, fixes text typed in the wrong layout and can switch the layout by itself. Written in FreeBASIC, based on LangBarXX (AutoHotkey, by Krot66): github.com/Krot66/LangBarXX.

Icon and flags

  • The notification area icon shows the flag of the layout of the window you work in. Left click - next layout, right click - menu.
  • A flag at the text cursor (if enabled in settings). Click it for the next layout; right click works like Break.
  • A flag at the mouse pointer: hidden, always shown, or shown for 3 seconds after a layout change (settings, "General").
  • When the layout changes, a large flag briefly appears in the middle of the screen.
  • Flag pictures are taken from the flags folder (ru-RU.png, en-US.png ...). Without a picture a colored rectangle with the country code is drawn.

Hotkeys

Change layout of selected textShift + Break

Transliterate selected textAlt + Scroll Lock

Hotkeys are changed in settings, "Hotkeys". There you can also make left Shift + Backspace and Ctrl + Caps Lock fix the last word.

Layout switching

  • A single press of left or right Shift or Ctrl - next, previous or a chosen layout. Double press can be required instead.
  • Left Ctrl, Alt or Win + digit 1-9 - the layout with that number.
  • Caps Lock: normal, disabled, next layout, last word in another layout, case of selected text.

Auto switching

Needs the Hunspell library and dictionaries (the hunspell and dict folders). If they are missing, the program offers to download them at first start; the "Download dictionaries" menu item does the same.

  • The start of a word is checked at the third letter, the whole word after a space. If the word is not in the current layout but is in another one, it is retyped and the layout changes.
  • Break right after an auto switch restores the word. That word is not switched again and, if enabled, is saved to user_dict.dic.
  • Words with digits, in capitals, or of one letter are not switched (configurable).

Switching rules

  • A rule is a set of letters, a condition (whole word, word start, word end or any part of the word), whether case matters, and an action: switch or don't switch. Rules are checked before the dictionaries, in list order; the first matching rule applies.
  • The letters are compared with the typed word in every layout: a rule for ghbdtn also applies to привет.
  • If automatic switching is undone with Break several times in a row (the number is set on the rules page), the program offers to add a "Don't switch" rule for the last word.

Settings

  • Stored in langbarfb.ini next to the program.
  • "Reset settings..." (icon menu or a button on the "General" page) restores defaults. The previous file is copied to the backup folder with the date and time in its name.
  • Interface language - Russian or English, changes after the program restarts.
  • "Start with Windows" writes to HKCU\Software\Microsoft\Windows\CurrentVersion\Run.
