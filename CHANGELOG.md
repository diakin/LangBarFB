# История изменений

## Не выпущено

- Исправление опечатки в последнем набранном слове по словарю Hunspell (Ctrl + Break): повторное нажатие даёт следующий вариант, после последнего возвращается исходное слово.
- Автоисправление опечаток после пробела (галка «Исправлять опечатки» на странице «Автопереключение», по умолчанию выключена): слово от 3 букв, которого нет ни в одном словаре, заменяется первым вариантом Hunspell; Break сразу после этого возвращает слово и запоминает его.
- Правила переключения (раздел настроек «Правила переключения»): сочетание букв, условие, регистр, действие «переключать» / «не переключать»; предложение добавить правило после нескольких отмен автопереключения подряд.
- Настройки «Точку не менять при смене раскладки текста» и «Запятую не менять при смене раскладки текста» (отдельно): при Break, Shift+Break и автопереключении этот знак остаётся как набран.

## 1.0 — 2026-10-26

Первый выпуск LangBarFB — переноса LangBarXX 1.8.4 на FreeBASIC.

- Флажок раскладки в трее, у текстового курсора и у указателя мыши; крупный флажок при смене раскладки.
- Переключение раскладки щелчком, одиночными Shift/Ctrl, Ctrl/Alt/Win + цифра, Caps Lock.
- Break, Shift+Break, Alt+Break, Alt+Scroll Lock: исправление последнего слова и выделенного текста, регистр, транслит.
- Автопереключение по словарям Hunspell, скачивание словарей, `user_dict.dic`.
- Окно настроек, сброс настроек с копией ini, автозапуск, «О LangBarFB», справка, интерфейс на русском и английском.
- Установщик на Inno Setup 5, только 32-битная сборка.
- Лицензия LGPL-3.0, как у LangBarXX.

На Windows 7 проверены значок, флажки, окно настроек, Break, Shift+Break и переключение одиночными клавишами. Автопереключение, флажок у мыши, сброс настроек, язык интерфейса и установщик проверены только компилятором — список проверок в [docs/testing.md](docs/testing.md).
