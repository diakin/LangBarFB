# userdata

Слова пользователя (`user_dict.dic`) и правила переключения (`rules.ini`, раздел `[Rules]`).

LangBarFB, запущенный из `bin` или `src` этого репозитория, находит эту папку (рядом с exe, на один или на два уровня выше — `bin`, `src`, `src\bin`) и хранит эти данные здесь, а не рядом с exe. Остальные настройки остаются в `langbarfb.ini` рядом с exe.

Сохранить на GitHub — `save_userdata.bat` в корне репозитория (коммит папки `userdata` в текущую ветку и push).

Установленная программа (без папки `userdata` рядом) хранит всё рядом с exe, как раньше.
