# LangBarFB

LangBarFB — переключатель раскладки клавиатуры на FreeBASIC. Это перенос [LangBarXX](https://github.com/diakin/LangBarXX) с AutoHotkey v1.1. Окна сделаны на RqLcl: это классы RapidQ поверх LCL, они лежат в репозитории [unIDE](https://github.com/diakin/unIDE), ветка `mainTest`, папка `RqLcl`.

План переноса по этапам лежит в [docs/plan.md](docs/plan.md).

## Состояние: этап 1

Этап 0 (хук клавиатуры и окна RqLcl на Windows) проверен: хук работает, обработчик укладывается в десятки микросекунд.

Сейчас программа делает следующее:

- запускается только одной копией и живёт в области уведомлений без окна;
- значок в трее — флажок раскладки окна, в котором работают. Флажок берётся из `flags\<код>.png` (`ru-RU.png`, `en-US.png` — те же имена, что у LangBarXX). Если файла нет, рисуется цветной прямоугольник с кодом страны (RU, US). Папка `flags` ищется рядом с exe и на уровень выше. Флажки можно взять из папки `flags` LangBarXX;
- под текстовой кареткой активного окна стоит маленький флажок 16 px. Положение задаёт константа `CARET_FLAG_BELOW` в `src/langbar.bas`: 1 — под кареткой, 0 — правее в той же строке (до окна настроек на этапе 4). Каретку пока видно только у окон с системной кареткой: Блокнот, поля ввода Windows, Delphi/Lazarus, Word. Браузеры и Electron — следующий шаг (Acc/UIA, как `GetCaretLocation.ahk`);
- при смене раскладки в том же окне посреди экрана на 0,7 с появляется крупный флажок (8 % ширины экрана); мышь проходит сквозь него;
- щелчок левой кнопкой по значку или по флажку у каретки переключает на следующую раскладку в окне, где работают;
- меню по правой кнопке: «Окно отладки» (нажатия, состояние хука, раскладка, флажки) и «Выход». Закрытие окна отладки только прячет его;
- хук `WH_KEYBOARD_LL` нажатия только наблюдает.

Код прошёл компилятор fbc 1.10.1 под Linux (win32 и win64, без сборки exe). На Windows эта часть ещё не запускалась.

## Сборка

Для сборки нужны:

- FreeBASIC для Windows, 32 и/или 64 бит;
- папка `RqLcl` из unIDE (ветка `mainTest`).

### Из unIDE

Откройте `src\langbar.bas`, выберите GUI и разрядность и запустите сборку. Нужна сборка unIDE не старше коммита ec2fa85: она сама добавляет `-i <RqLcl>\inc`, если в исходнике есть `#include "rqlcl.bi"`, и кладёт DLL рядом с exe. Папка RqLcl задаётся в IDE Options → Compilers → RapidQ Basic → RqLcl folder. Exe и DLL появятся в `src\`.

### Через build.bat

Скопируйте `build_local.bat.example` в `build_local.bat` и укажите свои пути. Сам `build_local.bat` в git не попадает.

```
set FB32DIR=D:\FreeBASIC-1.10.1-win32
set FB64DIR=D:\FreeBASIC-1.10.1-win64
set RQLCL=D:\unIDE\RqLcl
```

В каждой папке компилятор ищется как `fbc32.exe` / `fbc64.exe`, а если такого нет, как `fbc.exe`. Если `FB32DIR` / `FB64DIR` не заданы, компилятор ищется в PATH. Если не задан `RQLCL`, папка ищется в `..\unIDE\RqLcl`.

```
build.bat 32        rem bin\langbar32.exe + rqlcl32.dll
build.bat 64        rem bin\langbar64.exe + rqlcl64.dll
```

## Что проверить

1. Значок в трее показывает флажок раскладки активного окна и меняется вместе с ней (Alt+Shift, Win+Пробел, языковая панель Windows).
2. Щелчок по значку переключает раскладку в окне, где был курсор: в Блокноте, браузере, Word. После щелчка фокус возвращается в это окно.
3. В Блокноте флажок идёт за кареткой и меняется со сменой раскладки; щелчок по нему меняет раскладку, а фокус остаётся в Блокноте. Когда активна панель задач или окно без каретки, флажка нет.
4. При смене раскладки появляется крупный флажок и через долю секунды пропадает; при переходе в другое окно — не появляется.
5. Без папки `flags` рисуются текстовые флажки; с папкой `flags` из LangBarXX — картинки. Что найдено, видно в окне отладки.
6. «Выход» в меню убирает значок и завершает программу; второй запуск при работающей копии выдаёт сообщение.
7. В диспетчере задач («Объекты GDI», «Дескрипторы») числа не растут при частой смене раскладки и движении каретки.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `src/langbar.bas` | Главная программа: одна копия, форма, таймер, цикл сообщений |
| `src/core/winapi.bi` | Объявления функций Windows (префикс `Lb`, без windows.bi) |
| `src/core/kbhook.bi` | Хук клавиатуры и кольцевой буфер нажатий |
| `src/core/layouts.bi` | Список раскладок, раскладка окна, смена раскладки |
| `src/ui/tray.bi` | Служебное окно, значок и его меню |
| `src/core/caret.bi` | Положение каретки (GetGUIThreadInfo) |
| `src/ui/gfx.bi` | GDI+: флажок из png или текстовый, значок |
| `src/ui/overlay.bi` | Окна поверх всех: флажок у каретки, уведомление |
| `build.bat` | Сборка 32 и 64 бит |
| `build_local.bat.example` | Образец файла с путями к компиляторам и RqLcl |

Исходники `.bas`, `.bi` и `.bat` хранятся в CP1251 с CRLF, так же как в unIDE (`.gitattributes`, `working-tree-encoding`). Строки при передаче в RqLcl должны быть в CP1251.
