# LangBarFB

LangBarFB — переключатель раскладки клавиатуры на FreeBASIC. Это перенос [LangBarXX](https://github.com/diakin/LangBarXX) с AutoHotkey v1.1. Окна сделаны на RqLcl: это классы RapidQ поверх LCL, они лежат в репозитории [unIDE](https://github.com/diakin/unIDE), ветка `mainTest`, папка `RqLcl`.

План переноса по этапам лежит в [docs/plan.md](docs/plan.md).

## Состояние: этапы 1–3, часть этапа 4, этап 5 (автопереключение)

Этап 0 (хук клавиатуры и окна RqLcl на Windows) проверен: хук работает, обработчик укладывается в десятки микросекунд. Флажок в трее и у каретки (этап 1) проверен на Windows 7.

Сейчас программа делает следующее:

- запускается только одной копией и живёт в области уведомлений без окна;
- значок в трее — флажок раскладки окна, в котором работают. Флажок берётся из `flags\<код>.png` (`ru-RU.png`, `en-US.png` — те же имена, что у LangBarXX). Если файла нет, рисуется цветной прямоугольник с кодом страны (RU, US). Папка `flags` ищется рядом с exe и на уровень выше. Флажки можно взять из папки `flags` LangBarXX;
- под текстовой кареткой активного окна стоит маленький флажок 16 px (константа `CARET_FLAG_BELOW` в `src/langbar.bas`: 1 — под кареткой, 0 — правее в той же строке). Каретку пока видно только у окон с системной кареткой: Блокнот, поля ввода Windows, Delphi/Lazarus, Word. Браузеры и Electron — следующий шаг (Acc/UIA, как `GetCaretLocation.ahk`);
- при смене раскладки в том же окне посреди экрана на 0,7 с появляется крупный флажок;
- щелчок левой кнопкой по значку или по флажку у каретки переключает на следующую раскладку;
- меню по правой кнопке: «Настройки...», «Автопереключение», «Звуковые эффекты», «О LangBarFB», «Помощь», «Выход». Если открыть меню с нажатым Shift, в нём есть ещё «Окно отладки»;
- переключение с клавиатуры (раздел настроек «Переключение»):
  - одиночный левый или правый Shift, левый или правый Ctrl — следующая, предыдущая или выбранная раскладка. Срабатывает, если клавишу нажали и отпустили без других клавиш и щелчков мыши; можно включить срабатывание по двойному нажатию. Shift+буква и Ctrl+C при этом работают как обычно;
  - левый Ctrl, Alt или Win + цифра 1–9 — раскладка с этим номером в списке Windows;
  - Caps Lock: обычный, не действует, следующая раскладка, последнее слово в другой раскладке (как Break), регистр выделенного текста (как Alt+Break). Shift+Caps Lock при этом может включать и выключать Caps Lock;
  - Num Lock включается при запуске (по желанию);
- окно настроек с разделами «Общие», «Переключение», «Горячие клавиши», «Звуки», «Автопереключение». Настройки хранятся в `langbarfb.ini` рядом с exe;
- автопереключение (этап 5, подробнее ниже);
- горячие клавиши (сочетание глотается, в окно не попадает):

| Действие | По умолчанию |
| --- | --- |
| Отменить конвертацию раскладки: последнее набранное слово стирается и набирается заново в следующей раскладке, раскладка окна переключается. Повторное нажатие — следующая раскладка по кругу | Break |
| Сменить раскладку выделенного текста | Shift + Break |
| Сменить регистр выделенного текста (каждая буква наоборот) | Alt + Break |
| Транслитерировать выделенный текст (кириллица в латиницу, таблица LangBarXX) | Alt + Scroll Lock |

Break подробнее (этап 3):

- Break исправляет только последнее слово; повторное нажатие сразу после этого — то же слово в следующей раскладке по кругу. Целое предложение исправляют так: выделить и нажать Shift+Break;
- если набранного слова нет (после щелчка, Enter, в другом окне), Break исправляет выделенный текст, как Shift+Break;
- то же, что Break, делают правый щелчок по флажку у каретки и, если включены в разделе «Горячие клавиши», левый Shift+Backspace и Ctrl+Caps Lock.

Выделенный текст копируется через Ctrl+C, печатается заново поверх выделения и снова выделяется. Повторное нажатие того же сочетания сразу после этого возвращает исходный текст. Прежнее содержимое буфера обмена возвращается, если это был текст.

Автопереключение (этап 5):

- нужны библиотека и словари Hunspell: папки `hunspell` (`Hunspellx86.dll` для 32-битной сборки, `Hunspellx64.dll` для 64-битной) и `dict` (`dict\ru-RU\*.aff`, `*.dic` и т. д., имя папки — код раскладки). Они лежат в этом репозитории (взяты из установщика LangBarXX 1.8.4: en-US, ru-RU, uk-UA, be-BY, de-DE, fr-FR) и ищутся в папке из настроек («Автопереключение» → «Папка с hunspell\ и dict\»), рядом с exe и на уровень выше. Что загрузилось, видно на странице настроек и в окне отладки;
- если словарей нет, при первом запуске программа предлагает их скачать; то же делает пункт меню «Скачать словари». Файлы скачиваются по одному с GitHub (`raw.githubusercontent.com/diakin/LangBarFB/master/...`) в папку exe: библиотека и словари только тех языков, раскладки которых есть в Windows. Если с основного адреса файл не скачался, язык целиком берётся из репозитория словарей LibreOffice, а библиотека — из пакета NHunspell на nuget.org (подробнее в `dict/README.md`). Пункт «Словари других языков...» открывает папку словарей LibreOffice на Google Drive (та же ссылка, что в LangBarXX);
- начало слова проверяется на третьей букве (настройка «Проверять начало слова», включена по умолчанию; как «Обработка текста с 3-х символов» LangBarXX). При загрузке словаря строится таблица первых трёх букв всех слов: из основ `.dic` и приставок `PFX` из `.aff`. Если в раскладке набора слов с таким началом нет, а в другой раскладке есть, три буквы перепечатываются и раскладка меняется; дальше слово набирается уже в новой. На пробу (67 русских и 72 английских частых слова, набранных не в той раскладке) так ловится 55 и 61 слово; правильно набранные слова из этой выборки не переключались. Остальное ловит проверка после пробела;
- слово проверяется после пробела. Если в раскладке, где его набрали, его нет в словаре, а в другой раскладке есть, слово с пробелом стирается, печатается в той раскладке, и раскладка окна меняется. Если слово есть в обеих, переключение будет, только когда в другой раскладке у него больше букв (`;er` → `жук`);
- не проверяются: слова, которые правили Backspace; слова, посреди которых сменили раскладку; слова с цифрами и из одних заглавных (по настройкам); слова из одной буквы (по настройке); слова, начинающиеся с трёх одинаковых знаков;
- Break сразу после автопереключения возвращает слово в прежнюю раскладку и запоминает его: в этом сеансе оно больше не переключается, а с галкой «...в user_dict.dic» записывается в `user_dict.dic` рядом с exe. Этот файл (UTF-8, слово в строке, `;` — комментарий) читается при запуске; кнопка «Слова пользователя» открывает его в Блокноте. Дополнительные `.dic` в папке словаря раскладки добавляются к основному, как в LangBarXX;
- в окне отладки для каждого слова пишется, есть ли оно в словаре каждой раскладки и чем кончилось.

Этап 5 проверен только компилятором; на Windows он ещё не запускался.

Этап 3 прошёл компилятор fbc 1.10.1 под Linux (win32 и win64, без сборки exe). На Windows оно ещё не запускалось. Окно настроек запускалось на Windows 7; ошибка ModalResult при «OK» исправлена.

### Что пока отложено

- **Из этапа 5:** проверка после третьей буквы — только на третьей (у LangBarXX — на каждой клавише, с подсказками Hunspell); конец слова по Enter, Tab и знакам препинания (сейчас только пробел); режим одного языка и выбор языков автопереключения; уведомление и отмена по Ctrl+Z; предварительная проверка по таблице сочетаний клавиш (n-граммы). Звук «Конвертация текста в буфере» можно настроить, но он не звучит: этого действия ещё нет.
- **Каретка в браузерах** (Acc/UIA) — флажок у каретки там не появляется.
- **Чтение настроек LangBarXX** (`LangBarXX.ini`) — открытый вопрос плана; пока свой `langbarfb.ini`.
- **Буфер обмена** после действий с выделенным текстом восстанавливается только текстом: картинка или файлы, лежавшие там, пропадут.
- **Слово для Break** помнится по нажатиям клавиш. После щелчка мышью, Enter, Tab, стрелок, сочетаний с Ctrl/Alt/Win и смены окна оно сбрасывается. Если текст правили по-другому (вставка, автозамена в редакторе), Break может стереть не то.

### Что не переносится

По решению от 2026-10-26 из этапов 1–3 не делается:

- пометки Num/Scroll/Caps на значке в трее;
- сочетания Shift+Shift, Ctrl+Ctrl, Ctrl+Shift+Shift; короткое и долгое нажатие одиночной клавиши (есть обычное и двойное);
- Caps Lock «как Shift» и «коротко — Caps Lock, долго — регистр»; режимы Scroll Lock;
- правый Ctrl/Shift + цифра или F-клавиша;
- отдельные команды для нижнего, верхнего и «Как в предложении» регистра.

## Сборка

Для сборки нужны:

- FreeBASIC для Windows, 32 и/или 64 бит;
- папка `RqLcl` из unIDE (ветка `mainTest`).

### Из unIDE

Откройте `src\langbar.bas`, выберите GUI и разрядность и запустите сборку. Нужна сборка unIDE не старше коммита ec2fa85: она сама добавляет `-i <RqLcl>\inc`, если в исходнике есть `#include "rqlcl.bi"`, и кладёт DLL рядом с exe. Папка RqLcl задаётся в IDE Options → Compilers → RapidQ Basic → RqLcl folder. Exe и DLL появятся в `src\`.

### Через build.bat

Скопируйте `build_local.bat.example` в `build_local.bat` и укажите свои пути. Сам `build_local.bat` в git не попадает.

```
set FB32DIR=D:\FreeBASIC-1.10.1-win32
set FB64DIR=D:\FreeBASIC-1.10.1-win64
set RQLCL=D:\unIDE\RqLcl
```

В каждой папке компилятор ищется как `fbc32.exe` / `fbc64.exe`, а если такого нет, как `fbc.exe`. Если `FB32DIR` / `FB64DIR` не заданы, компилятор ищется в PATH. Если не задан `RQLCL`, папка ищется в `..\unIDE\RqLcl`.

```
build.bat 32        rem bin\langbar32.exe + rqlcl32.dll
build.bat 64        rem bin\langbar64.exe + rqlcl64.dll
```

## Что проверить

1. Правая кнопка по значку: меню из шести пунктов, «Настройки...» жирным. «Автопереключение» и «Звуковые эффекты» ставят и снимают галку; после перезапуска галки те же. «Помощь» открывает эту страницу. С нажатым Shift в меню появляется «Окно отладки».
2. Окно настроек: разделы переключаются; «Отмена» ничего не меняет; «OK» и «Применить» записывают `langbarfb.ini`.
3. «Запускать при старте Windows»: после «OK» в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` есть значение `LangBarFB` с путём к exe; после снятия галки его нет.
4. «Показывать флажок у текстового курсора»: снятие галки убирает флажок у каретки.
5. Горячие клавиши, «Назначить...»: окно ждёт сочетание, Esc — отмена. Новое сочетание сразу видно в списке; если оно было у другого действия, там оно снимается. После «OK» новое сочетание работает, старое — нет.
6. В Блокноте набрать `ghbdtn` и нажать Break: должно стать `привет`, раскладка — русская. Ещё раз Break — снова `ghbdtn` (при двух раскладках). С пробелом после слова (`ghbdtn ` + Break) пробел остаётся.
7. Выделить `ghbdtn vbh` и нажать Shift+Break: `привет мир`, текст остаётся выделенным; Shift+Break ещё раз — исходный текст.
8. Alt+Break на выделенном `пРИВЕТ` — `Привет`; Alt+Scroll Lock на `Щука ёж` — `Shhuka yozh`, раскладка английская. Меню окна после Alt+... не открывается.
9. Ctrl+Break и Break в консоли и в программах, где Break что-то значит, не доходят до окна, пока сочетание назначено.
10. Звуки: с папкой `sounds` из LangBarXX рядом с exe (или на уровень выше) Break и действия с выделением звучат; «Стандартный сигнал Windows» — вместо файлов системный звук; «Звуковые эффекты» в меню выключает все.
11. Окно отладки: проглоченные сочетания помечены «проглочена».
12. Переключение: в разделе «Переключение» поставить «Правый Ctrl — Следующая раскладка»; одиночное нажатие правого Ctrl меняет раскладку, а Ctrl+C, Ctrl+щелчок и правый Ctrl, нажатый и отпущенный после щелчка мыши, — нет. С «Срабатывать по двойному нажатию» раскладка меняется только от двух нажатий подряд.
13. Левый Ctrl + 1 / 2 — первая / вторая раскладка из списка Windows; цифра в окно не попадает. Для Alt + цифра меню окна не открывается, для Win + цифра — не открывается программа с панели задач.
14. Caps Lock в каждом режиме; при «Не действует» и других режимах Caps Lock не загорается, а Shift+Caps Lock (если галка стоит) включает и выключает его. Если Caps Lock горел в момент выбора режима, он гаснет.
15. «Включать Num Lock при запуске»: выключить Num Lock, запустить программу — он включается.
16. Предложение `ghbdtn vbh` выделить и нажать Shift+Break — `привет мир`, раскладка русская.
17. Щелчок мышью в другое место текста, затем Break на выделенном `ghbdtn` — исправляется выделенное.
18. Правый щелчок по флажку у каретки после набранного слова — как Break; левый щелчок по флажку по-прежнему меняет раскладку.
19. Галки «Левый Shift + Backspace» и «Ctrl + Caps Lock» в разделе «Горячие клавиши»: с ними эти сочетания исправляют слово, без них работают как обычно.
20. Автопереключение: положить рядом с exe папки `hunspell` и `dict` из LangBarXX (или указать папку в настройках и нажать «Перечитать словари»); в настройках должно быть «словари: ru-RU, en-US». В Блокноте в английской раскладке набрать `ghbdtn ` (с пробелом) — должно стать `привет `, раскладка русская, звук автопереключения. Сразу Break — снова `ghbdtn `, раскладка английская; второй раз `ghbdtn ` уже не переключается. В русской раскладке `руддщ ` → `hello `.
20а. Начало слова: в английской раскладке набрать `ghb` — сразу после третьей буквы должно стать `при`, раскладка русская, дальше слово набирается по-русски. В русской раскладке `руд` (hello) — `hel`. Обычный текст на третьей букве не переключается; в окне отладки видно «начало «...» есть/нет».
21. `USB`, `abc123`, `z`, слово, исправленное Backspace, — не переключаются (при галках по умолчанию). Обычный текст на русском и английском не трогается; в окне отладки видно, что проверялось.
22. «Автопереключение» в меню: снятая галка — слова не проверяются. Если словарей нет, при включении галки программа предлагает их скачать.
23. Скачивание: exe без папок `hunspell` и `dict` рядом и выше, в `langbarfb.ini` нет `DictAsked=1` — при запуске вопрос «Скачать?», после «Да» через несколько секунд сообщение «Словари скачаны», рядом с exe появляются `hunspell\` и `dict\<код>\`. Второй запуск вопрос не задаёт. Работает после вливания в master: файлы берутся оттуда.
24. Прежние пункты: флажок в трее и у каретки, уведомление, «Выход», одна копия; в диспетчере задач числа GDI-объектов и дескрипторов не растут.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `src/langbar.bas` | Главная программа: одна копия, меню значка, окно отладки, таймеры, цикл сообщений |
| `src/core/winapi.bi` | Объявления функций Windows (префикс `Lb`, без windows.bi) |
| `src/core/kbhook.bi` | Хук клавиатуры (кольцевой буфер нажатий, фильтр сочетаний) и хук мыши |
| `src/core/config.bi` | Настройки: `langbarfb.ini`, автозапуск, звуки |
| `src/core/hotkeys.bi` | Сочетания: запись словами, разбор, проверка в хуке, режим записи |
| `src/core/sendkeys.bi` | SendInput (клавиши, текст Unicode), буфер обмена, копирование выделения |
| `src/core/convert.bi` | Смена раскладки текста, регистр, транслит, буфер набранного слова |
| `src/core/actions.bi` | Действия горячих клавиш |
| `src/core/spell.bi` | Hunspell: загрузка библиотеки и словарей LangBarXX, проверка слова, `user_dict.dic` |
| `src/core/dictload.bi` | Скачивание библиотеки Hunspell и словарей с GitHub в отдельном потоке |
| `sounds/` | Звуки LangBarXX (autocorrect, undo, autoreplace) |
| `hunspell/`, `dict/` | Библиотека NHunspell и словари из установщика LangBarXX 1.8.4 |
| `src/core/autoswitch.bi` | Автопереключение: проверка слова после пробела и перепечатка |
| `src/core/switchkeys.bi` | Переключение с клавиатуры: одиночные Shift/Ctrl, Ctrl/Alt/Win + цифра, Caps Lock, Num Lock |
| `src/core/layouts.bi` | Список раскладок, раскладка окна, смена раскладки |
| `src/ui/tray.bi` | Служебное окно, значок и его меню |
| `src/core/caret.bi` | Положение каретки (GetGUIThreadInfo) |
| `src/ui/gfx.bi` | GDI+: флажок из png или текстовый, значок |
| `src/ui/overlay.bi` | Окна поверх всех: флажок у каретки, уведомление |
| `src/ui/dlg_settings.bi` | Окно настроек и окно «Назначить сочетание» (RqLcl) |
| `build.bat` | Сборка 32 и 64 бит |
| `build_local.bat.example` | Образец файла с путями к компиляторам и RqLcl |

Исходники `.bas`, `.bi` и `.bat` хранятся в CP1251 с CRLF, так же как в unIDE (`.gitattributes`, `working-tree-encoding`). Строки при передаче в RqLcl должны быть в CP1251.
